# Codex арқылы QIPIQ Mini V2 ашу

1. GitHub-қа кіріп, `didarradid93-ctrl/QIPIQ-Mini-V2` репозиторийінде файлдар бар екеніне көз жеткізіңіз.
2. ChatGPT Codex-та GitHub аккаунтыңызды қосып, осы репозиторийге рұқсат беріңіз. Егер репозиторий көрінбесе, GitHub Settings → Applications → Installed GitHub Apps ішінен Codex/ChatGPT қолданбасының repository access параметрін тексеріңіз.
3. Codex-та репозиторийді таңдаңыз.
4. Мына тапсырманы беріңіз: `Read AGENTS.md and CODEX_MASTER_PROMPT.md. Implement the next tested QIPIQ Mini V2 milestone. Keep a clear status report.`
5. Алдымен веб-демоны ашыңыз: `web-demo/index.html`. Бұл нақты құрылғы емес, браузер симуляциясы.
6. Құрылғыдағы зауыттық бағдарламаны резервтік көшірме жасамай өшірмеңіз.

## Құрылғы
Waveshare ESP32-S3-Touch-AMOLED-1.8 **V2**, CO5300 дисплей, CST820 сенсор. V1 бағдарламасы жарамайды.

## Тапсырмаларды орындау реті
- Ресми V2 драйверлерімен ESP-IDF минималды сынақ жобасын жинау.
- Экран және сенсор, IMU/RTC/аккумуляторды нақты платада тексеру.
- Анимациялық QIPIQ беті және мәзір.
- Микрофон/динамик, қазақша AI арқылы сөйлесу.
- Ойындар, автономды режим, батарея оңтайландыру және тестілеу.
