# Қай функция нақты жұмыс істейді?

| Мүмкіндік | Деңгей |
|---|---|
| Телефонда QIPIQ анимациялық беті | HTML/CSS жұмыс үлгісі |
| QIPIQ мәтіні → GPT жауабы | Сервер коды дайын, нақты кілт енгізген соң live сынау керек |
| Телефон микрофоны → STT | Сервер коды + браузер MediaRecorder, физикалық/browser сынау керек |
| GPT жауабы → телефон динамигі | Уақытша /audio/speech, кілтпен сынау керек |
| ESP32 Serial арқылы сұрау | Бастапқы .ino, физикалық тақшада сыналмаған |
| ESP32-нің өз микрофоны → ChatGPT | Әлі интеграцияланбаған |
| ESP32-нің өз динамигі → қазақша TTS | Әлі интеграцияланбаған |
| Қазақша мәтін экранға | UTF-8/Cyrillic GFX fonts әзірлеу қажет |

## Келесі физикалық аппараттық қадам

Waveshare SKU 33869 келуі, ресми мысалдарын жүктеу, I2S mic input және DAC/amp output pins дәл revision-нан тексеру, 16 kHz PCM clip жасау, Wi-Fi multipart upload, PCM/MP3 decoding, TTS buffer және динамик сынағы. Бұл жұмысты бір ретте дайын деп мәлімдеуге болмайды.

## Бизнес үшін

OpenAI billing бөлек, сервер хостингі бөлек, тасымал, сертификаттау, кепілдік шығыны бөлек. Дауыстық қосымшаның бағасы мәтінге қарағанда жоғары болуы мүмкін. Бір пайдаланушының күніне қанша диалог сөйлесетіні бойынша 10 құрылғылық бетаға дейін шығын шегін белгілеңіз.
