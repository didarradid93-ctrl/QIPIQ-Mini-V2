| Қазақша мәзір және таймер | V2 платада мәзір ашылды, таймер аяқталғанда дыбыс естілді |
| «Сан тап», «Шапшаңдық» және сақталатын баптаулар | V2 платада сан табылды, реакция уақыты өлшенді. Жарықтық, дыбыс және қозғалыс баптаулары жаңарту мен қайта жүктеуден кейін флештен расталды |
| QMI8658 қозғалыс реакциясы, AXP2101 батарея күйі, экранды бәсеңдету | V2 платада қозғалыс оқиғасы және AXP2101 іске қосылғаны тіркелді. Батарея орнатылмағандықтан, заряд пен жұмыс уақытын өлшеу қалды |
| Wi-Fi баптау және QR код | Пайдаланушы алғашқы сынақта үй желісіне қосылғанын хабарлады. Жаңартылған нұсқада QR экранға шығарылды. QR арқылы қосылу бөлек тексеріледі |
| Архивтегі standalone браузер демосы мен FastAPI backend | Prototype only |
| Архивтегі Arduino бұлт сынағы мен STL үлгілері | Prototype only |
| React демосы және қазақша AI дауысының құрылғыдағы интеграциясы | Not implemented |
| Бастапқы GitHub Actions тексерулері | Prototype only |
| ZIP жинағы және Windows орнатқышы | Жинақ тексерілді. Windows орнатқышы COM3 портына жазып, флеш деректерінің бақылау сомаларын растады |

Waveshare V2 тақтасында CO5300 (QSPI) және CST820 (I²C) қолданылады. Экран өлшемі 368 × 448. Тақтаның нұсқасын артқы жапсырмасынан тексеруге болады. [Waveshare құжаттамасы](https://docs.waveshare.com/ESP32-S3-Touch-AMOLED-1.8)

Дисплей мен сенсорды Waveshare BSP іске қосады. Құрастыру, жүктеу және қалпына келтіру қадамдары [firmware нұсқаулығында](../firmware/qipiq_v2/README.md).

Жоба түбірінен тестті іске қосу

```powershell
node --test tests/emotions.test.mjs
```
